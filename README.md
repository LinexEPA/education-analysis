# 教育訓練統計轉檔工具

GitHub Pages 前端，用於讀取院內教育訓練匯出的 `.ods` / `.xlsx` / `.xls` 檔案，於瀏覽器端辨識測驗與滿意度欄位，並提供測驗題目整段貼上與解析預覽。

## 第一版範圍

- 原始檔只在瀏覽器端解析，不上傳到 GitHub。
- 不顯示或保存姓名、身分證字號等個人識別欄位。
- 自動辨識課程代碼、資料筆數、測驗題數、滿意度題數。
- 自動計算測驗摘要：完測人數、平均分數、最高／最低分、及格率。
- 自動計算滿意度：1–5 分分布、平均分、各題滿意度、總滿意度。
- 支援整段貼上測驗題目與選項，建議格式：`[Q1]`、`[A]`、`[B]`、`[1]`、`[O]`、`[X]`。
- 解析後先預覽，題目數與原始檔不一致時會提示。

## 下一階段

接 Google Apps Script，依院內既定公版產出正式 Excel；原始檔沒有的固定欄位保留空白，不自行補值。
